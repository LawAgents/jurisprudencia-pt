# Supremo Tribunal Administrativo, processo 010368, 1978-03-09

## Sumário

A recusa de uma camara municipal de formalizar um contrato de troca de bens imoveis verbal constitui acto de direito privado, para cujo conhecimento são absolutamente incompetentes os tribunais administrativos.
