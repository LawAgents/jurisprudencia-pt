# Supremo Tribunal Administrativo, processo 007694, 1969-05-02

## Sumário

Para apurar o direito ao abono de familia não ha que descontar nos vencimentos dos conjuges a quotização para o Cofre de Previdencia do Ministerio das Finanças, nem as verbas para amortização de divida constituida para aquisição de uma casa atraves do mesmo Cofre.
