# Supremo Tribunal Administrativo, processo 020543, 1996-05-22

## Sumário

I - É considerado terreno para construção aquele que é destinado aos fins sociais de uma sociedade, especialmente para a construção de uma unidade fabril.

II - Trata-se de um terreno objectivamente para construção por se destinar à construção da unidade fabril e ser terraplanado.
