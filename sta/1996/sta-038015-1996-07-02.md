# Supremo Tribunal Administrativo, processo 038015, 1996-07-02

## Sumário

O patrono nomeado para o patrocínio de uma causa a instaurar impugnando uma deliberação camarária não se estende para novo processo judicial a intentar para impugnação de nova deliberação camarária no âmbito do mesmo processo administrativo.
