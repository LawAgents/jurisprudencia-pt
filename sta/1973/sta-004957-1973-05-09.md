# Supremo Tribunal Administrativo, processo 004957, 1973-05-09

## Sumário

Cometem uma tentativa de delito de descaminho os tripulantes de uma lancha que, no regresso de uma das suas viagens a Espanha, procuram introduzir no Pais varios artigos de roupa de senhora, ocultando-os no vestuario para assim os passar atraves de uma zona sujeita a fiscalização permanente, do que foram, porem, impedidos pelos agentes fiscais.
