# Supremo Tribunal Administrativo, processo 046032, 2006-05-16

## Sumário

Quando resultar dos autos que uma das partes faz sucessivos requerimentos com o fim de obstar à formação do caso julgado de uma decisão, pode o tribunal mandar subir os autos ao tribunal competente, para o qual fora interposto recurso daquela decisão.
