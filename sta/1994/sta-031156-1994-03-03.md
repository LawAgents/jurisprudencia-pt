# Supremo Tribunal Administrativo, processo 031156, 1994-03-03

## Sumário

Sendo de aplicar durante o procedimento administrativo, onde foi proferido o acto expropriativo recorrido, o anterior Código de Expropriações, nesse tempo vigente, é óbvio que o acto recorrido não enferma de vícios de forma resultantes da nova tramitação fixada no Código de Expropriações vigente, para aquele procedimento administrativo.
