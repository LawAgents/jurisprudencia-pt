# Supremo Tribunal Administrativo, processo 042116, 2000-05-16

## Sumário

Os tribunais Administrativos têm competência para qualificar certa conduta de militar da GNR como tendo natureza disciplinar para efeito de determinar se foi aplicada pela Administração uma medida lesiva, prevista no estatuto, tendo como base essa conduta que se considerou provada sem prévia instauração do respectivo procedimento para possibilitar a audiência e defesa dos interessados.
