# Supremo Tribunal Administrativo, processo 017927, 1985-04-26

## Sumário

Carecem de legitimidade para interpor recurso contencioso do acto de nomeação, por falta de interesse directo, os funcionarios que, a data do provimento dos lugares, não reuniam os requisitos indispensaveis para poderem ser nomeados.
