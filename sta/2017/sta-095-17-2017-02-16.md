# Supremo Tribunal Administrativo, processo 095/17, 2017-02-16

## Sumário

Não é de admitir a revista quando, tendo o Acórdão recorrido anulado o acto punitivo com fundamento em duas diferentes ilegalidades, o Recorrente requer a admissão do recurso para que se reanalise a bondade de uma delas.
