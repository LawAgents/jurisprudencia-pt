# Supremo Tribunal Administrativo, processo 017903, 1984-11-02

## Sumário

Carecem de legitimidade para interpor recurso contencioso do acto de nomeação, por falta de interesse directo, os funcionarios que, a data do provimento do lugar, não reuniam os requisitos indispensaveis para poderem ser nomeados.
