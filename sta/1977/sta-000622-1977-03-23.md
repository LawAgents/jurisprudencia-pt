# Supremo Tribunal Administrativo, processo 000622, 1977-03-23

## Sumário

Se uma sociedade cooperativa de construção continua a ser proprietaria dos bens imobiliarios construidos para os seus associados, ate integral pagamento do respectivo custo, a entrega desses bens aos associados, efectuada antes daquele pagamento, não constitui transmissão para efeitos de incidencia de sisa.
