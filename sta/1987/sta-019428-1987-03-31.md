# Supremo Tribunal Administrativo, processo 019428, 1987-03-31

## Sumário

O despacho, publicitado por editais dados a conhecer a uma cooperativa bem como o estudo tecnico para entrega para exploração a entidades singulares, ordenando a abertura de concurso para a entrega por arrendamento a entidades singulares, seria acto preparatorio de processo para entrega dos predios mas e acto destacavel para a cooperativa, na medida em que afasta esta de futuro uso dos predios, definindo-lhe assim a situação.
