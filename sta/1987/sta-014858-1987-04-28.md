# Supremo Tribunal Administrativo, processo 014858, 1987-04-28

## Sumário

O envio de guia pelo Instituto do Azeite e Produtos Oleaginosos para o deposito dos diferenciais não constitui acto administrativo definitivo e executorio, mas so o fornecimento dos elementos indispensaveis para o recorrente cumprir a obrigação que lhe foi imposta pela portaria.
