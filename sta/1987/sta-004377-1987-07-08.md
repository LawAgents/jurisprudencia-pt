# Supremo Tribunal Administrativo, processo 004377, 1987-07-08

## Sumário

Não contendo a sentença recorrida os necessarios elementos de facto para uma correcta decisão de direito, devem os autos baixar para que, fixados aqueles, se decida em conformidade com o direito aplicavel.
