# Supremo Tribunal Administrativo, processo 004705, 1956-05-04

## Sumário

Os donos dos predios marginais de aguas salgadas podem explora-los por meio de salinas.

A Administração so pode recusar-lhes licença para as obras necessarias para esse efeito se com elas se prejudicarem os interesses gerais ou os direitos de terceiro.
