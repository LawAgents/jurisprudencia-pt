# Supremo Tribunal Administrativo, processo 003396, 1951-02-09

## Sumário

É válido o despacho ministerial que se limitou a aplicar a um caso concreto as disposições genéricas do regulamento de uma caixa de previdência, as quais não foram impugnadas contenciosamente.
