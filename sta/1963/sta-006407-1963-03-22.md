# Supremo Tribunal Administrativo, processo 006407, 1963-03-22

## Sumário

Se um despacho ministerial, quando se concede autorização para se proceder a instalação de uma industria de montagem de automoveis, prescreve que e obrigatorio efectuar a coque, nos termos do Decreto-Lei n. 44104, não significa isso que seja concedida autorização para fabricar os paineis que constituem as carcaças ou cabinas dos veiculos, mas tão-somente para proceder a junção desses elementos.
