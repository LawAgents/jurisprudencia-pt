# Supremo Tribunal Administrativo, processo 043784, 1999-03-23

## Sumário

v É anulável contenciosamente o acto que indefere um pedido de asilo, o qual, julgando o mesmo fraudulento, se baseia para o efeito, parcialmente, em elementos de facto que são por si insusceptíveis de levar àquela conclusão.
