# Supremo Tribunal Administrativo, processo 003344, 1986-02-19

## Sumário

Não ha prazo para o cumprimento da obrigação para com o

Fundo de Desemprego, pelo que a mesma pode ser cumprida a todo o tempo. As quotizações para o Fundo de Desemprego são impostos.*
