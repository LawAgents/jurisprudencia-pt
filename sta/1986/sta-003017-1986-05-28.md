# Supremo Tribunal Administrativo, processo 003017, 1986-05-28

## Sumário

Mostrando-se insuficiente a materia de facto que permita fixar com precisão o regime juridico, devem os autos baixar a competente instancia para o seu oportuno apuramento e consequente decisão de direito.
