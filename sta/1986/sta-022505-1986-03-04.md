# Supremo Tribunal Administrativo, processo 022505, 1986-03-04

## Sumário

E acto confirmativo e, portanto, irrecorrivel o despacho que se limita a declarar que não se alegaram motivos suficientes para alterar o conteudo do despacho anterior, o qual se firmara na ordem juridica determinando o envio imediato do processo para cobrança coerciva se no prazo fixado se não provar o cumprimento das obrigações.
