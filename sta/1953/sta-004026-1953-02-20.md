# Supremo Tribunal Administrativo, processo 004026, 1953-02-20

## Sumário

Não constitui abertura de novo estabelecimento industrial, para efeitos de condicionamento, o desdobramento de duas secções independentes de uma unidade industrial, para o efeito de obter para cada uma delas matrícula independente.
