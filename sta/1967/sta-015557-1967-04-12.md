# Supremo Tribunal Administrativo, processo 015557, 1967-04-12

## Sumário

O mandato comercial so produz efeito para com terceiros desde a data do seu registo, pelo que os lucros de socio cujo mandato de gerencia não se mostra registado são, para efeitos fiscais, de socio não gerente.
