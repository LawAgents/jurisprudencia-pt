# Supremo Tribunal Administrativo, processo 006267, 1962-07-20

## Sumário

O condicionamento industrial visa não so as industrias mas os produtos fabricados, como tais se considerando os resultantes da montagem de simples peças adquiridas a fabricantes diversos para obtenção do produto acabado.
