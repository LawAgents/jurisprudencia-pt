# Supremo Tribunal de Justiça, processo 066282, 1976-07-27

## Sumário

I - Verifica-se trespasse quando no prédio negociado se continua a exercer o mesmo ramo de comércio e quando, além disso, se transferem para o adquirente os múltiplos elementos que formam o estabelecimento comercial.

II - No trespasse não está incluída a instalação telefónica se não tiver sido cedida com autorização dos TLP.
