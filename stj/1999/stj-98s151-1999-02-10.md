# Supremo Tribunal de Justiça, processo 98S151, 1999-02-10

## Sumário

Se uma sociedade transmite a exploração das suas cantinas a uma outra sociedade diferente daquela que as explorava, não se transmitem para esta os contratos de trabalho das trabalhadoras daquela primeira sociedade exploradora.
