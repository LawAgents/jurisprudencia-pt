# Supremo Tribunal de Justiça, processo 000988, 1985-05-28

## Sumário

I - Só depois de colhidos todos os elementos de facto, é que se poderá aplicar com precisão, o respectivo regime jurídico.

II - Não havendo suficiente base factual para a decisão de direito devem os autos baixar à Relação para alargamento da matéria de facto.
