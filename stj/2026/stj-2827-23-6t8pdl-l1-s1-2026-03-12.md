# Supremo Tribunal de Justiça, processo 2827/23.6T8PDL.L1.S1, 2026-03-12

## Sumário

Se os factos dados como provados não são suficientes para que se dê como verificado o elemento objectivo — corpus —, não faz sentido discutir-se se deve ou não dar-se como verificado o elemento subjectivo da posse — animus possidendi — pelo período necessário para a aquisição da propriedade por usucapião.
