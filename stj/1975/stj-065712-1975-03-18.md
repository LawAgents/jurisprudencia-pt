# Supremo Tribunal de Justiça, processo 065712, 1975-03-18

## Sumário

Não fornecendo os títulos existentes elementos de prova suficientes para se determinar qual a linha divisória entre dois prédios, é lícito o recurso à posse e outros meios de prova para se determinar a demarcação entre esses prédios.
