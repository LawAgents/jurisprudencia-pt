# Supremo Tribunal de Justiça, processo 084551, 1994-02-22

## Sumário

Se a divergência entre o acórdão recorrido e o acórdão fundamento se verificou não entre a parte dispositiva dos mesmos acórdãos mas entre as razões que fundamentaram a decisão, não existe contradição relevante para efeitos de recurso para o pleno.
