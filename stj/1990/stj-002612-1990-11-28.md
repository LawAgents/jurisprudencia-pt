# Supremo Tribunal de Justiça, processo 002612, 1990-11-28

## Sumário

A sociedade-mãe deve ser havida como entidade patronal real do trabalhador de uma sociedade filializada, se detiver de modo predominante o exercicio dos poderes patronais.
