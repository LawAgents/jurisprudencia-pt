# Supremo Tribunal de Justiça, processo 040961, 1990-11-28

## Sumário

I - Não é essencialmente militar (ou equiparado) o crime do mancebo que, apurado para o serviço militar, deixa de comparecer, quando convocado (refractário).

II - Logo, os tribunais comuns são os competentes, para o julgar.
