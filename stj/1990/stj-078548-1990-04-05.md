# Supremo Tribunal de Justiça, processo 078548, 1990-04-05

## Sumário

A emissão de uma letra não cria entre as partes uma nova relação juridica ( cambiaria ), extinguindo a subjacente, pelo que so se verifica a figura da novação quando as partes manifestem, de modo expresso, semelhante intenção.
