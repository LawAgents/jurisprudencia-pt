# Supremo Tribunal de Justiça, processo 084272, 1993-07-08

## Sumário

Para efeitos de recurso para tribunal pleno só se verifica o requisito da oposição de acórdãos quando existir identidade dos elementos relevantes para subsunção das respectivas situações à mesma regra jurídica.
