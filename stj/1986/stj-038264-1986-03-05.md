# Supremo Tribunal de Justiça, processo 038264, 1986-03-05

## Sumário

I - É competente para conhecer de uma infracção penal o tribunal em cuja área ela se consumou.

II - Quando houver acumulação de crimes pelo mesmo réu, o juízo competente para o julgamento é o da infracção a que corresponder pena mais grave.
