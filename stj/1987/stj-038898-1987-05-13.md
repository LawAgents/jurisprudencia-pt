# Supremo Tribunal de Justiça, processo 038898, 1987-05-13

## Sumário

I - Se a denuncia apontar para o cometimento de crime punivel com mais de 3 anos de prisão, o Ministerio Publico deve remete-la para o Juiz de Instrução.

II - O inquerito a que proceda não podera substituir a dita instrução, sendo nula a acusação que se faça sem esta, bem como nulos serão os actos posteriores.
