# Tribunal da Relação do Porto, processo 0536908, 2006-02-09

## Sumário

É possível a constituição de mais de um condomínio, com administração própria para gerir as partes comuns que servem apenas determinada zona de um edifício, ainda que para este tenha sido constituída uma só propriedade horizontal.
