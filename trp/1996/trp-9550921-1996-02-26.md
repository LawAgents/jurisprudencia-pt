# Tribunal da Relação do Porto, processo 9550921, 1996-02-26

## Sumário

I - Se no rés-do-chão dado de arrendamento para habitação os réus vêm utilizando, uma sala para nela servirem refeições ao público, há fundamento para a resolução do respectivo contrato com base no artigo 64 n.1 alínea b) do Regime do Arrendamento Urbano - uso do arrendado para fim diferente daquele a que se destina.
