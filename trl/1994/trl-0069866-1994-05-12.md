# Tribunal da Relação de Lisboa, processo 0069866, 1994-05-12

## Sumário

No processo de prestação de contas, quando estas são apresentadas pelo autor (depois de rejeitadas as oferecidas pelo réu), deve o juiz oficiosamente ordenar não só a correcção de eventuais irregularidades formais das contas como a recolha de elementos probatórios necessários para emitir uma decisão justa e criteriosa.
