# Tribunal da Relação de Lisboa, processo 0054431, 1992-06-16

## Sumário

O sinistrado é o exclusivo culpado se atravessa uma via sem verificar se o pode fazer sem perigo, olhando para ambos os lados, provocando o atropelamento por veiculo que se aproxima a velocidade reduzida.
