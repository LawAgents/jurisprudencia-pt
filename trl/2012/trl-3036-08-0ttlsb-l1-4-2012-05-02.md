# Tribunal da Relação de Lisboa, processo 3036/08.0TTLSB.L1-4, 2012-05-02

## Sumário

O recurso de apelação não é o momento processual adequado para se invocar a falsidade do depoimento de uma testemunha nos moldes contemplados no artigo 771º alínea b) do CPC para o recurso extraordinário de revisão.

(Elaborado pelo Relator)
