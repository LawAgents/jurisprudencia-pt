# Tribunal da Relação de Lisboa, processo 0028456, 1991-05-23

## Sumário

Se o seguro não cobre senão uma parte do valor da coisa segura, o segurado suporta uma parte proporcional do prejuízo, encontrando-se a indemnização, para o prejuízo, como a soma segura para o valor segurável, isto é, para o valor do objecto.
