# Tribunal da Relação de Évora, processo 616/17.6T8LLE-A.E1, 2019-03-28

## Sumário

Se findos os articulados, o juiz profere despacho a determinar a junção de documentos com vista a permitir a apreciação de uma excepção dilatória e, se decorrido esse prazo, se o mesmo for razoável, não existirem elementos nos autos que demonstrem que se encontra verificado o pressuposto processual, o incumprimento dessa determinação justifica que se conheça dessa questão controvertida com os dados relevantes existentes no contexto histórico, factual e jurídico conhecido pelo julgador.

(Sumário do Relator)
