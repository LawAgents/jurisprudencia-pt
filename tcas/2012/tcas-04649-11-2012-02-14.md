# Tribunal Central Administrativo Sul, processo 04649/11, 2012-02-14

## Sumário

I)- O Acórdão é obscuro quando se está perante um passo cujo sentido é ininteligível. Não se sabe o que o juiz quis dizer.

II)- Inexiste tal vício se o requerente se limita a focalizar aspectos que se mostram no Acórdão perfeitamente claros, pretendendo alterar o julgado.
